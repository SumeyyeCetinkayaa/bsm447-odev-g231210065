
# Rick and Morty Karakterleri

## Proje Bilgileri

- Ders: BSM447 Mobil Uygulama Geliştirme
- Öğrenci No: G231210065
- Konu: K22 - Rick and Morty Karakterleri
- Varyant: d - Ölmüş karakterler
- Ek Kural: 1 - Aşağı çekince yenileme

## Projenin Amacı

Rick and Morty dizisindeki ölmüş karakterleri listeleyen,
karakter detaylarını gösteren ve karakterlerin kalıcı
olarak kaydedilmesini sağlayan bir mobil uygulama geliştirmek.

## Kullanılacak Teknolojiler

- React Native
- Expo
- JavaScript
- React Navigation
- AsyncStorage

## API Adresi

https://rickandmortyapi.com/api/character?status=Dead

- Karakter Detayı
- Kaydedilenler
